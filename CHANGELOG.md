# Changelog

## v1.0.0
- Initial release
- Saves player inventory and equipment on death
- Spawns items as pickups at death location on return to the same map
- Only the most recent death stash is kept (new death overwrites)
- Disabled on permadeath maps (Apartments, Terminal)
- Stash is cleared on new game
- MCM settings: enable/disable, show hint message
- Works without MCM (falls back to local config)
- Pure autoload — no script overrides, maximum mod compatibility
